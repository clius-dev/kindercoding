==========================================================
  코딩유치원 B-2 — 코딩 개념 6가지 학습 화면
  배포용 (오프라인 단독 실행)
==========================================================

[ 1. 여는 방법 ]

  1) 받은 ZIP 파일을 마우스 오른쪽 클릭 → "압축 풀기" 를 누릅니다.
  2) 압축이 풀린 폴더를 엽니다.
  3) 폴더 안의  B-2_00.home.html  파일을 더블클릭합니다.
  4) 크롬(Chrome) 또는 엣지(Edge) 창이 열리면서 화면이 나타납니다.

  * 더블클릭했는데 메모장이나 다른 프로그램이 열린다면
    → 파일을 마우스 오른쪽 클릭 → "연결 프로그램" → "Chrome" 또는 "Edge" 선택


[ 2. 사용 방법 ]

  - 홈 화면에서 좌우로 밀거나 화살표를 눌러 6개 메뉴를 넘겨 봅니다.
      ALGORITHMS / SEQUENCING / DECOMPOSITION /
      BRANCHING  / ABSTRACTION / PATTERN RECOGNITION
  - 메뉴를 누르면 해당 학습 화면이 열립니다.
  - 화면 왼쪽 위의 "<" 버튼을 누르면 홈으로 돌아옵니다.
  - 오른쪽 위 "A한" 버튼으로 한국어 / 영어를 바꿀 수 있습니다.
  - 오른쪽 위 스피커 버튼으로 소리를 켜고 끕니다.

  * 태블릿·데스크톱 가로 화면에 맞춰 만든 화면입니다.
    브라우저 창을 넓게 키우면 가장 보기 좋습니다.


[ 3. 인터넷 연결 ]

  인터넷 없이도 그대로 동작합니다.
  글꼴, 그림, 아이콘, 소리, 스타일이 모두 파일 하나 안에 들어 있습니다.


[ 3-1. 소리에 대해 ]

  - 카드 효과음, 성공 소리, DECOMPOSITION 화면의 안내 음성은
    녹음된 소리 파일이 파일 안에 들어 있어 그대로 나옵니다.
  - 나머지 화면(ALGORITHMS / SEQUENCING / BRANCHING /
    ABSTRACTION / PATTERN)의 게임 설명 음성은
    윈도우·맥에 들어 있는 "읽어주기" 목소리로 나옵니다.
    이는 원본 화면과 동일한 방식입니다.
  - 소리는 화면을 한 번 누른 뒤부터 나옵니다.
    (브라우저가 첫 클릭 전에는 소리를 막습니다.)

[ 4. 파일 구성 ]

  B-2_00.home.html   ← 이 파일 하나가 전부입니다 (약 4.2MB)
  README.txt         ← 지금 보고 있는 안내문

  HTML 하나에 CSS, JavaScript, 이미지, 아이콘, 글꼴이 모두 들어 있어
  폴더를 옮기거나 이름을 바꿔도 화면이 깨지지 않습니다.
  파일 하나만 복사해서 보내도 그대로 열립니다.


[ 5. 확인된 환경 ]

  Chrome / Edge (Chromium 141 엔진 기준) 에서 동작을 확인했습니다.
  Windows, macOS 모두 같은 방식으로 열면 됩니다.
  인터넷 익스플로러(IE)는 지원하지 않습니다.


[ 6. 자주 있는 문제 ]

  Q. 화면이 하얗게만 보여요.
     → 파일을 끝까지 내려받았는지 확인해 주세요 (약 4.2MB).
        파일 크기가 작으면 전송이 중간에 끊긴 것입니다.

  Q. 글꼴이 달라 보여요.
     → 브라우저를 완전히 닫았다가 다시 열어 주세요.

  Q. 소리가 안 나요.
     → 화면을 한 번 클릭한 뒤에 소리가 나옵니다.
        (브라우저가 사용자의 첫 클릭 전에는 소리를 막습니다.)
        오른쪽 위 스피커 버튼이 꺼져 있는지도 확인해 주세요.
